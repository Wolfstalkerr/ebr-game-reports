Privacy Policy

This Privacy Policy describes how the EBR Game Reports automation system, operated by Eternal Beacon Roleplay, accesses and uses information provided through Google services.

Purpose of the application

EBR Game Reports is an internal administrative automation system used to process, organize, and maintain tabletop roleplaying game reports.

Google Drive access

The application may request access to Google Drive files used with the EBR Game Reports workflow. This access may be used to create, read, update, organize, or process files required for report automation.

The application is not intended to browse unrelated files in a user's Google Drive.

Use of Google user data

Google user data accessed by EBR Game Reports is used only to provide and operate the report automation functions requested by authorized Eternal Beacon Roleplay administrators.

Google user data is not sold, rented, or used for advertising.

Data sharing

Google user data is not shared with third parties except when necessary to operate services specifically configured as part of the EBR Game Reports workflow, or when required by law.

Data storage and security

Access credentials and automation configuration are restricted to authorized administrators. Reasonable measures are used to protect information processed by the system from unauthorized access, disclosure, alteration, or destruction.

Data retention and deletion

Information is retained only as necessary to operate and maintain the EBR Game Reports workflow. Authorized administrators may remove files, revoke Google account access, or discontinue use of the application.

Limited use

EBR Game Reports' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions regarding this Privacy Policy or the handling of information by EBR Game Reports may be directed to the administrator of Eternal Beacon Roleplay.
