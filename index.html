EBR Game Reports

EBR Game Reports is an internal automation system used by Eternal Beacon Roleplay to process and organize tabletop roleplaying game reports.

What the application does

The system uses Google Drive to access files that are specifically used as part of the EBR game-report workflow. It may create, read, update, organize, or process files required for report automation.

Access is limited to files used with the application and is not intended for general browsing of a user's Google Drive.

Who uses this application

This application is intended for authorized administrators of Eternal Beacon Roleplay and is not offered as a public consumer service.

Privacy

Information about how Google user data is accessed and handled is available in our Privacy Policy.

Contact

Questions regarding this application may be directed to the administrator of Eternal Beacon Roleplay.
